# Контекст для агентов

Этот каталог это стабильный технический контекст репозитория. Он дополняет `AGENTS.md` и `CLAUDE.md`, но не заменяет код, исполняемую конфигурацию и продуктовую документацию.

## Выборочное чтение

| Задача | Нужные файлы |
| --- | --- |
| Понять продукт, приложения или основной поток | `system-overview.md` |
| Менять API, аутентификацию, права или модули Nest | `backend.md`, `code-patterns.md` |
| Менять вход, сессии, ключи API, рабочее пространство, группы или spaces | `identity-access.md`, `backend.md` |
| Менять экраны, маршруты, состояние, формы или вызовы HTTP | `frontend.md`, `code-patterns.md` |
| Менять страницы, комментарии, вложения, шары или дерево | `content-workflows.md`, плюс `identity-access.md` там, где есть права |
| Менять редактор, Yjs, Socket.IO, коллаборацию или историю | `collaboration-realtime.md`, `content-workflows.md` |
| Менять схему, миграцию, хранилище, очереди, коллаборацию или окружение | `data-runtime.md`, при необходимости `backend.md` |
| Менять хранилище, почту, импорт, экспорт, фоновые задачи или проверку живости | `integrations-jobs.md`, `data-runtime.md` |
| Менять инструменты, аутентификацию или настройку MCP | `mcp.md`, `backend.md` |
| Менять ИИ, поиск, эмбеддинги или чат | `ai-search.md`, при необходимости `mcp.md` |
| Менять bases или шаблоны | `bases-templates.md`, `identity-access.md` |
| Менять SSO, SCIM, MFA, биллинг или верификацию страниц | `enterprise-security.md`, `identity-access.md` |
| Создавать или менять тесты, сборку, линт, Docker или деплой | `verification-operations.md` |
| Вносить изменение, пересекающее слои | Начать с `system-overview.md` и прочитать файлы затронутых слоев |

## Обязательное сопровождение

- Любое изменение обязано оценить, затронуло ли оно поведение, архитектуру, границу модуля, команду, конфигурацию или повторяющийся паттерн.
- Если затронуло, обновить соответствующий тематический файл в этой же работе и указать обновление в финальном ответе.
- Не обновлять контекст ради внутренних правок, которые не меняют перечисленные контракты. В финальном ответе заявить, что оценка сделана.
- Предпочитать проверяемые факты и пути в коде. Не копировать сюда большие блоки кода, полные списки эндпоинтов и планы текущих задач.

## Файлы

- `system-overview.md`: назначение, границы, пакеты, точки входа и потоки.
- `backend.md`: Nest и Fastify, модули, API, аутентификация, рабочее пространство и серверные интеграции.
- `frontend.md`: React и Vite, маршруты, организация кода, состояние, HTTP и коллаборация в браузере.
- `data-runtime.md`: база, миграции, генерируемые типы, окружение и сервисы времени выполнения.
- `identity-access.md`: аутентификация, сессии, ключи API, рабочие пространства, группы, spaces и авторизация.
- `content-workflows.md`: страницы, дерево, комментарии, вложения, шары, история и связанные возможности.
- `collaboration-realtime.md`: редактор Tiptap и Yjs, Hocuspocus, Socket.IO, персистентность и синхронизация через Redis.
- `integrations-jobs.md`: очереди, хранилище, почта, импорт и экспорт, статика, проверка живости, безопасность и телеметрия.
- `ai-search.md`: текстовый поиск, генеративный ИИ, чат, эмбеддинги и их требования.
- `bases-templates.md`: bases, формулы, шаблоны и текущие ограничения по реальному времени.
- `enterprise-security.md`: доступ к функциям, верификация страниц, SSO, SCIM, MFA и биллинг, включая известные пробелы.
- `mcp.md`: эндпоинт MCP, протокол JSON-RPC, инструменты, авторизация, ограничения и настройка.
- `code-patterns.md`: повторяющиеся паттерны реализации кода и тестов в обоих слоях.
- `verification-operations.md`: команды, CI, Docker, Open API и деплой.
