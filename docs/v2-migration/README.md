## Коротко

**153 040 строк production-кода**, 248 маршрутов, 44 таблицы, 505 компонентов,
38 представлений узлов редактора.

**Оценка: 14–20 месяцев** работы одного человека, и это уже с учётом того, что
три узла остаются на Node.

**Node из развёртывания не уходит.** Совместное редактирование, преобразование
содержимого страниц и экспорт DOCX остаются сервисом на Node, обоснование в
`04-blockers.md`.

**Решение принято: полная замена.** Ветка `v1` остаётся продом и живёт как
есть. Работа по v2 идёт только в ветке `v2` и никуда не выкатывается. Прод не
смешивает два стека ни на одном этапе.

**Боевой домен пока не трогаем.** Ближайшая цель — самостоятельное
развёртывание v2 на локальной машине, на `localhost`, целиком своим составом
compose. Порядок переключения живого домена написан и отрепетирован
(`09-switchover.md`), к нему возвращаемся по команде.

Решения по блокерам зафиксированы как принятые, не как варианты. Срок
14–20 месяцев остаётся в силе и не смягчается.

## Чего в этих документах нет

Шаблонов `clod-template-backend` и `claude-template-svelte`, на которые ссылается
задание, **в этом окружении нет**. Структура каталогов и правила выведены из
целевого стека и из устройства v1. Когда шаблоны появятся, расхождения надо
сверить.
