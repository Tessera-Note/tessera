# Что осталось сделать в v2

Опись остатка, снятая по коду 2 сентября 2026. Маршруты API сверены с экранами
`apps/web`, экраны v1 (`apps/client/src/App.tsx` в ветке `main`) — с маршрутами
v2, вызовы служб — с их применением в компонентах.

Уровень маршрутов закрыт целиком: см. `10-parity.md`. Остаток лежит выше — в
интерфейсе, в текстах, в проверках и в развёртывании.

## Как ведётся этот документ

Сделанный пункт помечается `[x]` здесь, а его подробности переносятся в
`done/NN-краткое-имя.md`: что было, что сделано, чем проверено. Здесь остаётся
одна строка со ссылкой. Документ закрыт, когда не осталось ни одного `[ ]`.

Порядок пунктов — порядок работы. Он же порядок важности: без первых пяти
вторая версия не заменяет первую.
