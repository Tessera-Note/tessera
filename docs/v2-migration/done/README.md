# Закрытые пункты

Каждый файл здесь — один закрытый пункт. Сами чек-листы тоже лежат здесь, они
закрыты целиком: `25-checklist-groups.md` (перенос, четырнадцать групп) и
`26-checklist-parity.md` (совпадение с v1, шесть разделов). Записи без пункта
(пришедшие из `../../future-roadmap.md`) говорят об этом в первой строке.

Открытая работа лежит в `../11-remaining.md`. Здесь её нет и быть не должно:
план содержит только то, что ещё делать.
Устройство записи одно и то же:

- **Было.** Состояние до работы, с путями в коде.
- **Сделано.** Что появилось, где лежит, какие решения приняты и почему.
- **Проверено.** Чем подтверждено: проверки, прогон, осмотр глазами.

Файл заводится в момент закрытия пункта, а не заранее. Пункт в чек-листе
помечается `[x]` и ссылается сюда.
