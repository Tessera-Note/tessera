# 9. Словари

## Было

Девять локалей отставали от источника на 932 ключа каждая: заведено было
1325–1367 из 2257. Недостающее показывалось по-английски — i18next при
отсутствии ключа падает на `en-US`.

Из 932 недостающих 411 — коды отказов, 521 — строки интерфейса.

## Сделано

Все девять локалей доведены до полноты: `de-DE`, `es-ES`, `fr-FR`, `it-IT`,
`ja-JP`, `ko-KR`, `nl-NL`, `pt-BR`, `zh-CN` — по 2257 ключей, столько же,
сколько в источнике. Русская и украинская были полны и раньше.

Порядок ключей в файлах сохранён, новые дописаны в конец: пересортировка дала
бы правку в две тысячи строк, за которой не видно содержательной.

**Переводы сделаны в этой работе и носителями языка не вычитаны.** Это надо
знать, принимая результат: они грамотны и единообразны по терминологии, но
проверки живым носителем не проходили. Прежнее состояние — английская фраза в
девяти интерфейсах — хуже, поэтому работа сделана; вычитку стоит запланировать
отдельно.

Терминология держалась единой по каждому языку: «пространство», «страница»,
«рабочее пространство», «вложение», «база», «представление» переводятся во всех
932 строках одинаково.

## Проверено

- `pnpm --filter @tessera/web test` — 189 проверок, зелёные. Из них о словарях:
  разбор всех двенадцати файлов, отсутствие пустых значений, отсутствие
  синтаксиса ICU, сохранность подстановок источника, парность скобок, полнота
  форм числа у славянских языков, наличие всех ключей кода в источнике.
- Пересчёт по каждому файлу: недостающих ключей ноль во всех локалях.
