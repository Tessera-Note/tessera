# 32. Словари v2 в Crowdin

Пункт 3 из `../11-remaining.md`.

## Было

`crowdin.yml` знал только словари v1: `apps/client/public/locales/<локаль>/
translation.json`. Двенадцать словарей v2 (`apps/web/static/locales/<локаль>.json`)
и тексты писем заведены переводами, сделанными в работе, и вычитки носителями
не проходили.

Оставить как есть значило бы, что в день смены прода синхронизация уходит не
туда, а заметить это нечем: файлы просто перестанут обновляться.

## Сделано

В `crowdin.yml` добавлен второй источник. Раскладка у версий разная: у v1
каталог на локаль, у v2 один файл на локаль с именем локали, — поэтому это
именно второй блок, а не правка первого.

Блок v1 оставлен. Снять его раньше смены прода значит перестать обновлять
переводы работающей вики.

## Проверено

Осмотром файла и разбором его как YAML: два источника, оба с типом
`i18next_json`, шаблоны путей совпадают с раскладкой на диске.

Согласованность самих словарей держит `apps/web/src/lib/i18n/dictionaries.test.ts`:
каждый ключ из кода заведён в источнике, состав локалей одинаков, славянские
формы на месте.
