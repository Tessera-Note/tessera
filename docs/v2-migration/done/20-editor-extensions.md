# 20. Расширения редактора

## Было

В v1 перечень расширений содержит пятнадцать имён, которых нет в v2. Схему
узлов ни одно не трогает — расхождения документов они не давали, — но
поведение редактора было беднее.

## Сделано

### Таблицы

Подключены четыре расширения из общего пакета: перетаскивание строк и
столбцов, действия у ручки, закрепление шапки и сортировка в режиме чтения.
Вместе с ними — те же настройки таблицы, что в v1 (`resizable`,
`allowTableNodeSelection`, `cellMinWidth`, `View`): они участвуют в
перетаскивании, а `View` даёт ту обёртку, к которой цепляются закрепление и
сортировка.

Оформления этих четырёх в v2 не было вовсе; перенесено из
`features/editor/styles/table.css` v1 на цвета v2.

### Вставка и копирование

`MarkdownClipboard` — вставленный простой текст разбирается как Markdown, а
скопированный список уходит в буфер Markdown'ом. Перенесено с одной правкой:
распознавание одиночной ссылки написано своё. Библиотека распознавания в
составе зависимостей проекта не объявлена, а нужен здесь один вопрос — один ли
это адрес целиком.

`CleanStyles` — срезание `style` при вставке из Word и почты.
`AutoJoiner` — слияние соседних списков: без него отмена правки и вставка
между списками оставляют два вплотную, и нумерация начинается заново.
Взято из v1 с заменой `getNodeType` из обвязки React на тот же из `@tiptap/core`.

Разбор ширин столбцов вставленной таблицы вынесен в отдельный
`extensions/table-widths.ts`: в Markdown ширин нет, и без них таблица сжимается
под редактор вместо того, чтобы прокручиваться.

### Подсказки, счёт и выделение

`Placeholder` был подключён только к комментарию; у страницы не было ни одной
из четырёх подсказок v1. Подключён, переводчик передаётся доводом — перечень
расширений собирается один раз на редактор и хранилища языка не знает.

`Selection` — украшение выделения, когда редактор потерял фокус: без него
выделенное пропадает с глаз, стоит нажать кнопку панели.

`CharacterCount` подключён вместе с тем, что его читает: **в боковой панели
страницы не было раздела «Статистика»**, который есть в v1. Заведён: слова,
знаки, дата создания и дата правки. Счёт идёт по документу редактора, а не по
разметке — разметка несёт узлы без текста, и счёт по ней расходился бы с тем,
что человек видит написанным.

`SharedStorage` не подключён и не нужен: в v1 он держит местные предпросмотры
картинок, пока те грузятся, а v2 грузит файл до вставки узла
(`done/01-editor.md`) — предпросмотров не бывает.

### Языки подсветки

v1 доучивает `lowlight` девяти языкам сверх общего набора; в v2 их не было.
Перенесены все девять. `mermaid` объявлен обычным текстом намеренно: это не
язык подсветки, а пометка для отображения блока.

### Найденный дефект: диаграмма не рисовалась после перезагрузки

Библиотека диаграмм грузится по требованию, и сборщик находил её только в миг
первого обращения. Её собственная зависимость поставляется в старом формате
модулей, разбор на лету давал отказ «модуль не отдаёт такого имени», и
диаграмма молча оставалась текстом. Библиотека объявлена в `optimizeDeps`.

### Правка сторожевой проверки словарей

Имя расширения (`name: 'autoJoiner'`) — тоже поле `name`, но не подпись.
Правило уточнено структурно: подпись в этом коде всегда английская фраза с
заглавной, имя узла или расширения — одно слово со строчной.
