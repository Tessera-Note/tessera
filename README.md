
## Features

- Real-time collaboration
- Diagrams (Draw.io, Excalidraw and Mermaid)
- Spaces
- Permissions management
- Groups
- Comments
- Page history
- Search
- File attachments
- Embeds (Airtable, Loom, Miro and more)
- Translations (10+ languages)

## Установка

Развёртывание с нуля описано в `docs/deployment-from-scratch.md`: порядок
первого запуска, обязательные переменные, создание первой учётной записи,
обязательные и необязательные службы.

```
git clone git@github.com:Tessera-Note/tessera.git
```

Репозиторий закрытый, нужен доступ к организации `Tessera-Note`.
